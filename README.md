# Calculadora (Suma) Simple con TDD

Este proyecto implementa una calculadora básica en Python aplicando la metodología TDD (Test Driven Development).

## Aplicación de TDD

### RED 🔴

Se creó inicialmente la prueba unitaria antes de implementar el método `sumar`. La prueba falló porque la funcionalidad aún no existía.

### GREEN 🟢

Se implementó el método `sumar` con el código mínimo necesario para hacer pasar la prueba unitaria correctamente.

### REFACTOR 🔵

Se mejoró el método agregando validaciones para verificar que los parámetros fueran numéricos, manteniendo todas las pruebas exitosas.
